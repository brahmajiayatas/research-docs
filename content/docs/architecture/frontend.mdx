## Web

Next.js + React + TypeScript

Recommended UI:

- Next.js
- React
- TypeScript
- Tailwind CSS
- shadcn/ui
- React Hook Form
- Zod

Why:

- excellent form workflows
- server-side rendering
- strong TypeScript ecosystem
- scalable SaaS architecture
- easy deployment
- good developer productivity

## Mobile

Initially make the product **responsive web/PWA**.

Later:

**React Native / Expo**

for:

- notifications
- secure messaging
- document approvals
- mediation updates
