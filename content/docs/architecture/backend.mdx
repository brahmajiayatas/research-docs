## Primary API

NestJS + TypeScript

Architecture:

```
API Gateway
     │
     ├── Authentication
     ├── Case Management
     ├── Party Management
     ├── Mediation Engine
     ├── Decision Engine
     ├── Evidence Engine
     ├── Document Engine
     ├── Notification Engine
     └── AI Gateway
```

## Alternative

Python/FastAPI can be used for specialized AI services.

Therefore:

```
Next.js
   ↓
NestJS
   ↓
PostgreSQL
   ↓
AI Gateway
   ↓
Python AI Services
```

See also [Frontend](/architecture/frontend) and [Infrastructure](/architecture/infrastructure).
