## Guided AI

Avoid a generic ChatGPT-style interface as the primary product.

Instead use **Guided AI**:

```
AI:
"We're working on the family-home issue.

I have identified three possible paths.

Would you like to:
[Review Options]
[Add Information]
[Make a Proposal]
[Ask a Question]"
```

This keeps the user inside the workflow.

See also [Closed AI](/ai/closed-ai).
