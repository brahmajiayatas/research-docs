## Deterministic backbone

The decision-tree engine should be the deterministic backbone of the platform.

The AI explains and assists.

The decision engine determines workflow.

## Example

```
START
 │
 ├── Are both parties participating?
 │       │
 │       ├── NO → Invitation Workflow
 │       │
 │       └── YES
 │
 ├── Is there a dispute?
 │       │
 │       ├── NO → Agreement Preparation
 │       │
 │       └── YES
 │
 ├── What issue?
 │
 ├── Children
 ├── Property
 ├── Support
 ├── Debt
 ├── Retirement
 ├── Taxes
 └── Other
```
