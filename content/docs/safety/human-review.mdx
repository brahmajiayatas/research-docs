## Mediator dashboard

```
Active Cases
 ↓
Risk Alerts
 ↓
Unresolved Issues
 ↓
Missing Documents
 ↓
Pending Proposals
 ↓
Impasse Cases
 ↓
Agreement Review
```

Mediator can:

- review AI summaries
- correct information
- approve workflows
- pause AI
- send messages
- add notes
- request documents
- escalate issues
