Because divorce cases contain extremely sensitive information, security should be treated as a core product capability rather than an afterthought.

## Authentication

- OAuth 2.0
- OpenID Connect
- MFA
- passkeys where appropriate

## Authorization

Use RBAC + case-level access control.

Example:

- Platform Admin
- Mediator
- Spouse A
- Spouse B
- Attorney
- Financial Professional
- Support

A spouse must never be able to access the other spouse's private workspace.

## Encryption

- TLS 1.3
- AES-256 at rest
- encrypted backups
- KMS-managed keys

## Security monitoring

- immutable audit logs
- suspicious-login detection
- access alerts
- document-access tracking

OWASP's current guidance specifically highlights LLM risks such as prompt injection, sensitive-information disclosure, supply-chain issues and improper output handling.
