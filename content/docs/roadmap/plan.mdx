---
title: Delivery plan
description: Development roadmap from discovery through production, including AI evaluation, pilot, and launch gates.
---

## Delivery phase 1 — Discovery

2–4 weeks

Deliver:

- PRD
- legal requirements
- jurisdiction scope
- UX architecture
- threat model
- decision-tree specification

## Delivery phase 2 — Architecture

2–3 weeks

Deliver:

- database architecture
- API specification
- AI architecture
- security architecture
- decision engine architecture

## Delivery phase 3 — UX/UI

3–5 weeks

Design:

- onboarding
- dashboards
- case workspace
- issue workspace
- negotiation interface
- mediator dashboard

## Delivery phase 4 — MVP Development

10–16 weeks

Build:

- Frontend
- Backend
- Database
- Decision Engine
- AI Gateway
- Document Engine
- Mediator Portal
- Security

## Delivery phase 5 — AI Evaluation

4–6 weeks

Test:

- hallucination
- prompt injection
- privacy leakage
- incorrect extraction
- unsafe recommendations
- biased responses
- workflow bypass
- escalation failures

## Delivery phase 6 — Pilot

Start with a limited number of cases and professional oversight.

## Delivery phase 7 — Production

After validation:

- security testing
- penetration testing
- legal review
- AI evaluation
- compliance documentation
- production deployment
